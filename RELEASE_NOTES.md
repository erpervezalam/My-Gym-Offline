# Release Notes

## 0.5.0 — 2026-09-14

### Highlights

- Refreshed every screen with responsive Material 3 layouts, compact grids and lists, title-cased exercise text, and support for light, dark, and system appearance.
- Improved exercise browsing with image-led cards, clearer in-media reaction controls, search on demand, and reliable back navigation.
- Redesigned exercise details so the media is prominent, controls stay accessible, and long instructions scroll independently.
- Simplified settings, including a compact language selector, expandable debug tools, an efficient equipment filter, and dataset credit.
- Bundled the complete offline GIF library and added an optional custom GIF-folder selector. Custom files are validated before use and fall back safely to bundled media if unavailable.

### Quality and privacy

- Added coverage for navigation preferences, filtering, display text, reactions, custom GIF validation, and the bundled GIF catalogue.
- Runs fully offline: no network permission and cleartext network traffic disabled.
- The app does not restore custom GIF-folder settings to a device that lacks the corresponding storage permission.

### Known release packaging detail

- The release APK is approximately 146 MB because it includes the complete 1,324-file animated GIF library for offline use.
